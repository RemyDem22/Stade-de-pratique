# Outdoorvision
Pipeline de traitement géospatial des discontinuités linéaires

# Installer les dépendances
Le code s'éxecute dans un environnement Pyhton, avec les librairies présentes dans requierments.txt

# Formats supportés
GeoPackage (.gpkg)
GeoJSON (.geojson)
